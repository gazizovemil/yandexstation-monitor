# История версий

## 1.0.1 — исходники для GitHub

- Повторные запросы к Yandex API при кратковременных сетевых ошибках, SSL-тайм-аутах, HTTP 429/5xx (максимум три попытки, паузы 3 и 6 секунд).
- Записи о начале и завершении каждого цикла автоматического мониторинга.
- GitHub Actions: тесты при пуше в `main`, публикация Docker Hub по тегам `v*`.
- Unit-тесты парсинга устройств, отказоустойчивости API, протокола отправки в Zabbix.
- Документация для Portainer, TNAS и безопасной работы с OAuth.

## 1.0.0 — первоначальная работающая версия

- Яндекс Станция по Glagol с OAuth Яндекс Музыки (Device Code).
- Умная розетка Яндекса по официальному Smart Home API, разрешение `iot:view`.
- Zabbix sender/trapper + два XML-шаблона Zabbix 8.2.
- Docker-контейнер, автоматический опрос каждые 300 секунд.
