# Безопасность

Сервис **только читает** состояние розетки и Станции. Для розетки используется OAuth с правом `iot:view` без `iot:control`. Для неофициального Glagol используется отдельный OAuth-токен Яндекс Музыки — он более привилегированный и должен храниться как пароль.

## Никогда не публикуй

- `data/`, `config.json`, `plug.json`
- `.station_music_token`, `.iot_view_token`, `.session_id`
- `.env`, любые cookies, client secrets или OAuth-токены
- логи, содержащие случайно выведенные секреты

Файлы данных сохраняются за пределами Docker-образа: `/Volume1/docker/yandexstation-monitor/data`. `.dockerignore` содержит белый список только из `Dockerfile` и `monitor.py`.

Если секрет попал в GitHub, **немедленно отзови токен в аккаунте Яндекса**, затем удали секрет из истории Git (удаление последним коммитом недостаточно). Не присылай секреты при создании issues.

Zabbix trapper ограничивай известным IP шлюза Docker-сети, а не `0.0.0.0/0`. Контейнер не требует привилегий, Docker socket и входящих портов.

Локальный Glagol может использовать самоподписанный TLS-сертификат. Отключение проверки TLS используется только для WebSocket соединения с IP колонки, но не для HTTPS-запросов в Яндекс.
